# InfinityExpansion

Plugin addon này bổ sung nhiều vật phẩm cuối game, như "Thỏi vô cực" tiêu tốn nhiều tài nguyên. Thỏi vô cực có thể dùng để chế tạo trang bị và máy móc mạnh mẽ.
